# Sicherheit

## Sicherheitslücke melden

Bitte melde mögliche Sicherheitsprobleme **nicht** als öffentliches Issue, sondern vertraulich über
**Security → Report a vulnerability** in diesem Repository (GitHub Private Vulnerability Reporting).

Beschreibe bitte, was passiert, wie es sich nachstellen lässt und welche Version betroffen ist.

## Was Tokenmeter tut und was nicht

- Keine Netzwerkzugriffe, keine Telemetrie
- Keine Dateizugriffe, kein Lesen von Chat-Inhalten
- Keine Zugangsdaten oder API-Keys
- Keine externen Abhängigkeiten

Pull Requests, die Netzwerkzugriffe, Abhängigkeiten oder das Auslesen von Daten hinzufügen, werden nicht angenommen.

## Unterstützte Versionen

Nur die jeweils neueste Version erhält Korrekturen.
